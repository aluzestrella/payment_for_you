WEBSITE KEJUTAN V2 — UNDER THE SAME MOON

FITUR
- 5 halaman interaktif: payment, receipt, universe, gallery, closing note.
- Animasi bintang bergerak dan meteor; ilustrasi Taurus dihilangkan.
- Ilustrasi bulan bercahaya dan mengambang.
- Konstelasi Taurus dengan SVG dan garis bintang.
- Cumi-cumi kecil yang bergerak pelan.
- Transisi halaman dan indikator progres.
- Galeri hingga 50 foto; foto dibuka dalam tampilan layar penuh dengan caption singkat berbeda, navigasi foto, dan tombol panah keyboard.
- Musik latar mulai dicoba pada halaman 3 dan berulang (loop). Pesan penutup halaman 5 memiliki efek ketik perlahan.

SEBELUM PUBLIKASI
1. Edit script.js dan ganti CORRECT_PIN = "DDMMYYYY" dengan PIN 8 digit kalian.
2. Letakkan file MP3 milikmu di assets/music.mp3.
3. Letakkan foto .jpg di assets/photos/ dengan nama photo-01.jpg sampai photo-50.jpg.
4. Tes dengan membuka index.html di browser.

AUTOPLAY
Browser dapat membatasi autoplay bersuara. Tombol verifikasi pada halaman pertama adalah interaksi pengguna, sehingga pemutaran dicoba ketika halaman 3 dibuka. Jika ditolak browser, klik/tap sekali lagi untuk memulai musik. Musik tetap loop selama halaman terbuka.

GITHUB PAGES GRATIS
1. Buat repository GitHub baru.
2. Upload isi folder ini ke root repository (index.html harus langsung di root).
3. Repository > Settings > Pages.
4. Build and deployment: Deploy from a branch.
5. Branch: main, folder: /(root), lalu Save.
6. Tunggu publikasi. URL berbentuk https://USERNAME.github.io/NAMA-REPOSITORY/

Tidak perlu database, backend, framework, package manager, atau build step.

CATATAN PRIVASI
PIN pada situs statis hanyalah gerbang kejutan, bukan perlindungan keamanan. Jika repository public, source code dan PIN dapat dibaca orang lain. Jangan taruh informasi sensitif di dalamnya.

OPTIMASI
Kompres foto ke sekitar 1200 px sisi terpanjang dan JPEG quality 75–85. Gunakan ukuran MP3 seperlunya agar cepat dibuka lewat ponsel.
